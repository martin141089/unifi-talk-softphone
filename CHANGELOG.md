# Changelog

Alle nennenswerten Änderungen an diesem Add-on werden hier dokumentiert.

Die für Home Assistant maßgebliche Version dieser Datei liegt unter
[unifi-talk-softphone/CHANGELOG.md](unifi-talk-softphone/CHANGELOG.md) (dort liest der
Supervisor sie aus).

## [0.2.1]

### Geändert
- Eigener TURN-Server (coturn) durch Cloudflare Realtime TURN ersetzt - Telefonie
  von unterwegs braucht dadurch keine Portfreigabe am Router mehr. Details siehe
  [unifi-talk-softphone/CHANGELOG.md](unifi-talk-softphone/CHANGELOG.md).

## [0.2.0]

### Hinzugefügt
- Anrufe im Dashboard annehmen und per Browser-Audio führen (WebRTC-Brücke,
  eingebauter TURN-Server). Details siehe
  [unifi-talk-softphone/CHANGELOG.md](unifi-talk-softphone/CHANGELOG.md).

## [0.1.0]

### Hinzugefügt
- Erste Version: SIP-Client + Anrufer-Übersicht + geführte Setup-Anleitung für den
  UniFi-Talk-Softphone-Workaround. Details siehe
  [unifi-talk-softphone/CHANGELOG.md](unifi-talk-softphone/CHANGELOG.md).
